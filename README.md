# CS370-Current-and-Emerging-Trends-in-Computer-Science
Learning about current/emerging trends in AI's reinforcement learning algorithms.

<h2 align="center">Pirate Intelligent Agent: Reinforcement Learning</h2>

<h3>Project Overview</h3>

This project involved developing an intelligent agent that learns to navigate a maze and find treasure using reinforcement learning. The agent uses a neural network to help determine which actions to take as it explores the environment and learns from its experiences.

The goal was to train the pirate agent to find a successful path through the maze by learning which actions lead to rewards and which actions result in penalties.

This project demonstrates how reinforcement learning and neural networks can be applied to problem-solving and decision-making.

<h3>What I Did</h3>

I was provided with starter code that established the maze environment, managed the agent's experiences, and supplied the basic structure needed to train the intelligent agent. This included the <i>TreasureMaze.py</i> and <i>GameExperience.py</i> files, along with a Jupyter Notebook containing the starter code.

My primary responsibility was to complete and improve the <b>qtrain()</b> function in the Jupyter Notebook. I developed the training logic that allowed the agent to explore the maze, choose actions, store experiences, and learn from previous attempts.

<h4>My work included:</h4>

Implementing the agent's training process using Q-learning concepts.

Using a neural network to estimate the value of possible actions.

Applying exploration and exploitation strategies so the agent could explore new paths while learning from previous experiences.

Using stored experiences to train the neural network.

Adjusting training parameters to improve efficiency and learning performance.

Testing the trained agent to evaluate whether it could successfully navigate the maze and reach the treasure.

The project required troubleshooting errors, reviewing training results, and adjusting the code to improve the agent's learning process.

<h3>What I Learned</h3>

<h4>Reinforcement Learning and Neural Networks</h4>

I learned how reinforcement learning allows an intelligent agent to improve its decisions through experience and feedback. Instead of following a predetermined path, the agent learns which actions are more beneficial based on rewards and penalties.

I also learned how neural networks can estimate the value of possible actions and help an agent make decisions. Combining these concepts allows a program to learn strategies for solving problems rather than relying entirely on explicitly programmed instructions.

<h4>What Do Computer Scientists Do, and Why Does It Matter?</h4>

Computer scientists solve problems by designing, developing, testing, and improving software and computational systems. Their work can help automate tasks, analyze information, improve decision-making, and address challenges in many industries.

This project demonstrated how computer science can be used to develop systems that learn from experience. Reinforcement learning has potential applications in robotics, logistics, game development, and other areas where systems must make decisions based on changing conditions.

Understanding how these systems work is important because their decisions can affect people, businesses, and society.

<h4>How Do I Approach a Problem as a Computer Scientist?</h4>

I approach problems by breaking them into smaller parts, understanding the requirements, identifying possible solutions, and testing those solutions.

During this project, I worked with existing code, identified areas that needed to be completed, and developed the training logic required for the intelligent agent. When problems occurred, I examined the code and training results, made adjustments, and tested the changes.

This experience reinforced the importance of persistence, logical thinking, debugging, and evaluating results rather than assuming that code is working correctly simply because it runs without errors.

<h4>What Are My Ethical Responsibilities to the End User and the Organization?</h4>

Computer scientists have a responsibility to develop systems that are reliable, secure, fair, and appropriate for their intended purposes. They must consider how software decisions affect end users and the organizations that depend on those systems.

When developing intelligent agents, it is important to recognize that a system's decisions depend on its training, data, and design. An agent that performs well in a test environment may not perform equally well in a different environment.

My responsibility as a computer scientist is to test software carefully, identify limitations, communicate results honestly, and consider potential risks before recommending a system for practical use.

Protecting user information, maintaining system security, and avoiding misleading claims about a system's capabilities are also important ethical responsibilities.
